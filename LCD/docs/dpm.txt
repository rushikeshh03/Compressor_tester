1 Scope

This communication protocol adopts CAN specification version 2.0B, 29-bit identifier, and

extended frame.

   2 Range

This CANbus communication protocol describes the external CAN communication protocol

of Beian New Energy Co., Ltd. It is applicable to the 10kW series, 12kW series, 20kW series, 30kW

series charging modules and laser power supplies and other power modules produced by Beian

New Energy Co., Ltd.

3 Physical communication interface

Canbus. Baud rate 125kbps/s

4 Frame Structure

5 Frame Example.

1. Broadcast setting the module ON/OFF

Send ID 1907C080 Data 2 0 0 0 0 0 0 55

Return ID                   Data

Broadcast command no reply

2. Setting the module 1 POWER ON/OFF
     Send ID 1907C081 Data 2 0 0 0 0 0 0 55
     Return ID 1807C081 Data 2 FF 0 0 0 0 0 0
    If the setting is successful, Byte1 will return FF; if it fails, it will return 00.

3. Setting the module 3 output voltage and current

     Send ID 1907C083 Data 0 01 5F 90 00 01 86 A0

     Return ID 1807C083 Data 0 FF 0 0 0 0 0 0
    Module 3 setting the output voltage 100V, Current 100A
    100V = 100*1000 = 100000mV = 0x186A0
    90A = 90*1000 =90000mA = 0x15F90
    If the setting is successful, Byte1 will return FF; if it fails, it will return 00.

4. Read module 2 status information

Send ID 1907C082 Data 1 0 0 0 0 0 0 0

Return ID 1807C082 Data 1 0 01 17 03 E8 0 0

Output Voltage Value: Byte4~Byte5       0x03E8 = 1000/10  100V
Output Current Value: Byte2~Byte3       0x0117 = 279/10  27.9A
Output Status: Byte6~Byte7              0x00 0x00 Normal, No warning.

5. Read module 1 output voltage

6 Cautions

1. During the soft-start process, the module cannot be directly loaded. It can only be loaded after
    the output voltage of the module is established (output is stable). This can be determined by
    checking the module status flags (refer to Table 6-1 and Figure 6-1).

2. The output current of the module should be gradually increased in steps. For example, if the

    required current is 100A, the initial current setting can be set at 10A, and then increase by 10%
    of the load current, i.e., in increments of 10A, 20A, ....... , 90A, 100A. It is recommended that the
    current ramp-up time be  1 second.
